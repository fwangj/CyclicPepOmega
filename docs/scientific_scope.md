# Scientific scope

CyclicPepOmega organizes public experimental structural evidence around:

```text
Modification -> Conformation -> Recognition -> Selectivity
```

Chemical changes such as N-methylation, L/D inversion, residue substitution,
noncanonical components, ring-size changes, and altered crosslinks can reshape a
macrocycle. The platform records chemically interpretable identities and
modifications so their observed torsional, geometric, polarity, and hydrogen-bond
consequences can later be compared.

A single bound structure lacks conformational context. Multiple coordinate
observations of the same identity must remain distinct so apo/bound, target-to-target,
and multi-model comparisons can be made without confusing observation with identity.

Generic contact lists also do not establish transferable recognition principles.
The intended recognition layer links a conformation ID to an interface observation
and atom-level interactions, enabling future tests of how residue presentation and
interface chemistry differ between conformations and targets.

Version 0.2.0 provides transparent structural measurements and candidate mappings.
It does **not** predict affinity, selectivity, permeability, conformational free
energy, conformational selection versus induced fit, or the solution global minimum.
Claims of novelty or general recognition rules require later systematic validation.
